# Security reporting

Please report suspected vulnerabilities privately rather than including exploit
details, credentials or business data in a public issue.

**Owner action required:** replace `security@<your-domain>` with a monitored
security contact before deployment. This is a placeholder, not a working address.
Until it is replaced, contact Madtech Solutions through your existing private
project contact channel. Do not send reports to the placeholder address.

Include the affected revision, steps to reproduce, expected and observed results,
and the potential impact. Use a test account and redact customer information,
passwords, session cookies and database connection details.

Forge is currently a development-stage operational ERP. Documented production
security hardening is planned for later phases. This reporting policy does not
claim that Phase 0 implements those later protections.
